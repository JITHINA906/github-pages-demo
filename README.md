# Host a Static Website with GitHub Pages

## Objective
Deploy a static website using GitHub Pages.

## Tools and Technologies
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Visual Studio Code

## Project Description
Created a simple static website using HTML and CSS. The website was uploaded to a GitHub repository and deployed using GitHub Pages, making it accessible online through a public URL.

## Project Structure
```text
github-pages-demo/
├── index.html
├── style.css
└── README.md
```

## Implementation Steps
1. Created an `index.html` file to define the website structure.
2. Created a `style.css` file to customize the website design.
3. Tested the website locally using a web browser.
4. Initialized a Git repository.
5. Added and committed the project files.
6. Pushed the project to a GitHub repository.
7. Enabled GitHub Pages from the repository settings.
8. Selected the `main` branch and the root folder as the deployment source.
9. Verified the published website using the GitHub Pages URL.

## Git Commands Used
```bash
git init
git add index.html style.css README.md
git commit -m "Add static website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/github-pages-demo.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

## Deployment Configuration
- Hosting Platform: GitHub Pages
- Branch: `main`
- Folder: `/ (root)`
- Entry File: `index.html`
